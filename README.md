# Enterprise Project Risk Management

## Overview
Risk management project focused on identifying, measuring, prioritizing, and mitigating financial, technical, and operational risks.

## Work Performed
- Built a 20-risk enterprise risk register.
- Applied Expected Monetary Value (EMV) analysis to quantify potential financial exposure.
- Used probability-impact analysis to prioritize identified risks.
- Developed risk mitigation recommendations and a risk management plan.

## Skills Demonstrated
- Risk Assessment
- Risk Register Development
- Probability-Impact Analysis
- Expected Monetary Value Analysis
- Risk Prioritization
- Risk Treatment Planning

## Deliverables
- Risk Register
- Risk Management Plan
- EMV Analysis
